# 판정 근거와 검증 범위

2026-10-30 보완본 반영. 현재 출처 번호는 problem.yaml의 R1~R9를 따른다. 과거의 R1~R11 번호와 15도·10% 근거 주장은 현재 계약이 아니다.

| 근거 | 역할과 한계 |
|---|---|
| E1 | 사용자가 친구에게 알려준 관찰. 반응·효과는 미확인 |
| E2 | 본인의 반복·뻐근함 자기보고. 횟수·인과·효율 영향 미확인 |
| R1 | 대학생 설문의 관련성. 현재 전체 대학생·노트북만의 평균으로 확대하지 않음 |
| R2~R4 | 피드백의 효과와 작업 부담·불확실성. 자동 경고 단독 효과가 아님 |
| R5 | 유사 공개 프로젝트. 독창성·우월성 입증이 아님 |
| R6 | 작업 환경·자세 안내. 웹캠 판정 임계값이 아님 |
| R7~R9 | 정면 특징 계산·분류 가능성의 참고. 제품 정확도·임상 정상선이 아님 |

보완자료는 2026 연구의 KCI 주소(R8)를 제공했다. 이전 문서의 “찾지 못함”은 아카이브의 당시 기록으로 남기고, 현재는 제공 자료의 확인 기록으로 인용한다. 이번 통합에서 모든 원문을 독립 재검증하지 않았으며 그 사실을 sources에 표시했다.

머리–어깨 관계·얼굴 면적·어깨 변위를 후보 특징으로 검토한다. 실제 조합·진입/복귀 경계·민감도·신뢰도·측면 배치·동기화 오차는 데이터로 정한다. 얼굴 크기만으로 목 전진을 확정하지 않고, 어깨 기울기만으로 둥근어깨를 판정하지 않는다. C7을 측정하지 않는 대체 지표를 CVA로 표시하지 않는다.

개인 기준도 의학적 정상 인증은 아니다. 자세 안내와 측정 성공을 구분한다. 등록 5초·최초 경고 10초·복귀 3초·재경고 60초·자동 리포트 유효 30분은 이번 사용자 요청으로 통일한 현재 기본값이다. 논문이 입증한 최적값은 아니다. 공통 정책과 용어는 planning-policy.yaml을 따른다. 사람·촬영 세션을 나눠 독립 참조와 오경고·놓침을 검증한 후 판정 규칙을 확정한다.

현재 서비스명은 패스트거북이이다. 자리 비움·인식 불가에서는 판정과 경고·유효 시간 누적을 보류하고 이탈·복귀·재경고 연속 타이머를 초기화한다. 로그인 없이 같은 PC 사이트·브라우저 프로필에 로컬 저장하며 IndexedDB/localStorage의 선택을 감지 성능·의학적 타당성 근거로 사용하지 않는다.
