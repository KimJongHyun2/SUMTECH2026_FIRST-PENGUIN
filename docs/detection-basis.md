# 판정 기준 근거 — 무엇을 재고, 왜 그 수치인가

> [prd.md](prd.md) 7장의 근거 문서. 팀 조사 문서(개발 상세, 판정 기준 근거, 2026-10-29)를 옮겼다. **아래 자료는 팀 조사 문서에 적힌 것이고, 이 저장소에서 원문을 다시 열어 확인하지는 않았다.** 확인한 뒤 problem.yaml `sources`로 옮긴다.

## 1. 결론 먼저

- 정면 웹캠으로 **자세 변화 정보**를 얻을 수 있다 — 근거 있음
- **개인 기준 + 복수 특징 조합** — 직접 연구 있음(국내 2021·2026)
- 정면에서 모든 사람에게 적용할 **"거북목 정상 각도"는 확정할 수 없다** — 논문 실험값과 의학 표준을 구분해야 함
- 논문 정확도를 우리 제품 정확도로 쓸 수 없다. 얼굴 면적 10%는 의학적 경계가 아니다. 정면만으로 CVA를 재지 못한다
- 따라서 명세에 넣을 수 있는 기준은 **"KOSHA 안내로 등록한 개인 자세 + 정면의 얼굴–어깨 비율·얼굴 면적·어깨 변위의 복합 변화"**. 최종 임계값은 제품 검증 실험으로 정한다. **문헌 조사는 마쳤고 제품 실험은 아직이다.**

## 2. 기준 자세 등록 안내 — KOSHA GUIDE E-G-3-2025 (6.3 작업자세)

| 항목 | 등록 때 안내 | 정면 웹캠으로 확인 |
|---|---|---|
| 머리·목 | 화면을 몸 앞에 두고 자연스러운 중립 자세 | 방향은 가능, 앞뒤 정렬은 제한적 |
| 어깨 | 으쓱하지 않고 윗팔 자연스럽게 내림 | 위치 변화 측정 가능 |
| 화면 거리 | 눈–화면 40cm 이상 | 거리 보정 없이는 cm 판정 불가 → 안내만 |
| 화면 배치 | 약간 아래를 보도록 | 별도 확인 필요 |
| 팔·손목·등·발 | 팔꿈치 90° 이상, 등받이·발 지지 | 웹캠으로 확인 불가 → 자가 확인 |

처음 카메라에 보이는 자세를 그대로 기준으로 저장하지 않는다. 안내를 거쳐도 웹캠이 전신 자세를 인증한 것은 아니다. 장시간 노트북 사용 시 외부 키보드·마우스 안내(영국 HSE).

## 3. 정면 지표의 직접 근거

| 지표 | 연구 | 계산 | 한계 |
|---|---|---|---|
| A. 턱·광대–어깨 거리 비율 | 「웹캠 기반 거북목 판별 알고리즘을 활용한 자세 교정 반응형 헬스케어 시스템」(국내, 2021) | 광대·턱에서 어깨 평균 수평선까지 수직거리 3개 ÷ 광대 너비 | 7명, 테스트 자료를 튜닝에도 사용 |
| B. 얼굴 면적 변화 + 어깨 변위 | 「인공지능 기반 자세 추정 모델을 활용한 실시간 거북목 증후군 검출 시스템」(국내, 2026) | 양눈·코끝 삼각형 면적의 기준 대비 변화율 + 어깨 수직·수평 변위. 논문 설정: 면적 +10% 등 휴리스틱 | 26명·60cm·5자세. 임상 교차검증 없음, 픽셀 임계값은 기기 종속 |
| C. 코–목 거리 ÷ 양눈 거리 | 2024 학회 | 특정 촬영 조건에서 1.9를 후보 경계로 제안 | 성인 5명, 연출 자세, CVA 대조 없음 → 확정 기준으로 쓰지 않음 |
| 정면–측면 관련성 | Molaeifar 등, 2021 (58명, 8대 카메라, 해부학 표식) | 흉골 중점–양 이주 정면 각도와 3D CVA 사이 중등도 상관 | 단일 웹캠 검증 아님. 어깨 중점·귀 관절점으로 바꾸면 다른 측정값 |

→ **A를 우선 시험 지표로, B를 함께** 본다. 얼굴만 커졌다고 거북목으로 확정하지 않는다(의자·카메라 이동). 머리·어깨 기울기는 보조.

## 4. 확정 가능한 수치 / 불가능한 수치

| 수치 | 판단 |
|---|---|
| 눈–화면 40cm 이상 | 공식 배치 안내에 사용 가능 |
| 얼굴 면적 증가 10% | 논문 재현 실험의 **출발값**으로 사용 가능 |
| 코–목/양눈 비율 1.9 | 해당 논문 촬영 조건에서 시험 가능 |
| 어깨 기울기 5°면 경고 | 보편적 근거 확보 못함 |
| 머리 높이 10% 감소면 거북목 | 보편적 근거 확보 못함 |
| 정면 귀–어깨 각도에 CVA 50° 적용 | **적용하면 안 됨** (측정 지표가 다름). MediaPipe 기본 관절점에 C7 없음 → 어깨점을 C7 대신 넣고 CVA라 표시 금지 |

## 5. 단계별 시간·각도 근거 (판정 기준 근거 문서)

| 단계 | 값 | 근거 | 우리 적용 |
|---|---|---|---|
| 주의 | 바른 자세 대비 15° 이상이 **30초** 지속 | 웨어러블 자세 센서 연구(ResearchGate 330977633), 안과 전공의 실시간 자세 피드백(PMC12292650), ErgoAssist(arXiv 2609.00440, 프리프린트), plumbcoach 블로그(논문 아님) | **30초**를 경고 시간 기본값으로 차용. 15°는 정면에서 못 재므로 비율 임계값(출발값 10%)으로 대체 — 실험 |
| 위험 ① | 20° 이상 | RULA (ErgoPlus 가이드·Companion PDF; 원 논문 McAtamney & Corlett 1993) | 민감도 "낮음" 쪽 임계값 설계에 참고만 |
| 위험 ② | CVA 48~50° 미만 | J Rehabil 2015(DOAJ), MEJRH(Brieflands), CVA 참고값 리뷰(PMC11042887), JRCRS | **측면 전용** → 딥 모드 때. 정면에 적용 금지 |
| 리포트 | 각도 × 유지 시간 | ISO 11226:2000 | 이탈 누적 시간·비율로 리포트 |
| 회복 | 10° 미만으로 **5초** 유지 | 근거 없음 — 깜빡임 방지 설계값 | 복귀 확인 5초 |

학술 논문이라 할 수 있는 것은 CVA 4개 + 웨어러블·안과 2개. ErgoPlus는 실무 가이드, ISO는 표준, plumbcoach는 블로그, ErgoAssist는 심사 전.

## 6. 아직 해야 하는 검증

사람과 촬영 세션을 분리한 평가에서 측면 참조 측정과 비교하고, **놓친 이탈**과 **시간당 오경고**를 함께 확인해 임계값을 확정한다. 자세 변화 자체를 모두 나쁘게 보지 않는다 — 공식 안내(HSE)는 휴식과 움직임을 권장하므로, 순간 움직임은 허용하고 지속 이탈에만 경고한다.
