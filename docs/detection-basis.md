# 판정 근거와 검증 범위

문제·기술 근거는 [problem.yaml](problem.yaml)의 R1·R2·R5~R11을 사용한다. R3·R4는 [PRD의 리스크 및 검증 계획](prd.md#10-리스크-및-검증-계획)에서 관리한다.

| 근거 | 역할 |
|---|---|
| E1 | 새벽 캡스톤 회의실에서 동료의 자세 지적 뒤 몸 상태를 알아차린 경험이다. |
| E2 | 기숙사 밤샘 알고리즘 과제 후 목·허리 불편을 알아차린 경험이다. |
| E3 | 도서관에서 3시간 연속 인강을 본 뒤 장시간 같은 자세였음을 알아차린 경험이다. |
| R1 | 대학생 156명 조사의 디지털기기 사용 환경과 통증 관련성이다. |
| R2 | 영상 피드백·교육·자기 점검의 복합 개입 참고이며 작업 부담을 함께 평가한다. |
| R5 | 개인 기준 보정·웹캠 알림의 유사 공개 프로젝트이다. |
| R6 | 작업 환경과 자세 안내를 위한 KOSHA 권고이다. |
| R7~R9 | 턱선·어깨 관계, 얼굴 면적 변화, 코–목 거리와 양안 거리 비율 등 영상 특징 설계의 참고이다. |
| R10 | 질병관리청의 장시간 고개 숙인 기기 사용과 목·어깨 통증 설명이다. 인원 통계는 아니다. |
| R11 | 심평원 자료를 인용한 2019년 보도의 2013·2018년 수치이다. 현재 규모·대학생 유병률로 확대하지 않는다. |

팀의 five_whys는 작업 몰입·주의 배분·자세 미인지에 관한 문제 분석이다. 인터뷰가 뇌의 통증 처리 기전을 측정한 자료라는 뜻은 아니다. 세 경험 기록을 세 명의 독립된 표본으로 환산하지 않는다.

머리–어깨 관계·얼굴 면적·어깨 변위를 후보 특징으로 검토한다. 실제 조합·진입/복귀 경계·민감도·신뢰도·측면 배치·동기화 오차는 데이터로 정한다. 얼굴 크기만으로 목 전진을 확정하지 않고 어깨 기울기만으로 둥근어깨를 판정하지 않는다. C7을 측정하지 않는 대체 지표를 임상 CVA로 표시하지 않는다.

개인 기준은 비교 기준이다. 등록·경고·복귀·재경고·리포트 정책은 [PRD](prd.md)의 5절과 8.2절을 따른다. 정책값은 제품 설계값이며 논문이 입증한 최적값이 아니다. 사람·촬영 세션을 나눠 독립 참조와 오경고·놓침을 검증한 후 판정 규칙을 확정한다.

자리 비움·인식 불가에서는 판정·경고·유효 시간 누적을 보류하고 연속 타이머를 초기화한다. 성공 지표 R=D/V×100은 확정 개인 기준 이탈의 시간 비율이다. 인지까지 걸린 시간은 별도 사용자 관찰에서 확인한다. 화면 상태 문구 ‘거북목이에요’는 개인 기준 이탈 안내이며 진단으로 해석하지 않는다.
