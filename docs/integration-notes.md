| 가상 계산 actual vs 실행 결과 | 원본은 가상 산술 자료로 보관, 별도 독립 재계산. 앱 성공으로 쓰지 않음 |

| source 확인 상태 | 원문의 확인 기록을 인용하되 이번 독립 재검증 여부를 명시 |

## 후속 정합성 작업 — 2026-10-30

사용자가 구현 없이 기획 문서만 정리하고, 시간값·자리 비움·로컬 저장·스타터 양식을 통일하도록 요청했다. 기존 작업 트리에는 수정 사항이 없었으며 앱 코드는 변경하지 않았다.

| 항목 | 현재 처리 |
|---|---|
| 스타터 원문 | 요청 API에 POST한 응답의 다운로드 주소로 새 ZIP을 받고 별도 임시 폴더에서 안내·양식·규격을 확인했다. 기존 저장소 생성·배포 작업은 반복하지 않았다. |
| 단계 진행 안내 | 스타터의 단계별 멈춤·새 기획 질문 지침과 달리 이번 요청은 이미 정해진 세 정합성 작업을 순차 완료하도록 명시했다. 기존 결정·근거를 재정리하고 새 경험·기능·수치를 만들지 않았다. |
| 시간값의 상태 | 등록 5초·최초 경고 10초·복귀 3초·재경고 60초·자동 리포트 유효 30분을 이번 사용자 지정 기본값으로 명시했다. 과거의 ‘승인 전 파일럿 제안’ 표시는 이 다섯 값의 현재 상태가 아니다. 의학적·사용성 검증은 여전히 미완료이다. |
| 보조 설계값 | QR 120초·연결 2/6/10초·보관 30일·설정 허용 범위는 기존 설계안으로 유지하고 이번에 새로 승인받은 값으로 쓰지 않았다. |
| 단일 기준·용어 | planning-policy.yaml에 공통 기본값·중단 규칙·용어를 모았다. problem.yaml·scenarios.yaml·prd.md·집계 계약은 같은 정의를 사용한다. |
| 자리 비움 | 판정 보류, 후보 폐기/확정 이탈 중단, 이탈·복귀·재경고 연속 타이머 초기화, 정상 복귀 제외를 명시했다. 세션 누적 유효 시간은 유지하고 중단 시간은 제외한다. |
