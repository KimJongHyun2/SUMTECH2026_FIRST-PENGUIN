# 기획 평가 대응 메모

현재 기획 점수는 사용자 확인 기준 **30점 만점에 14.6점**, 목표는 **20점대 이상**이다. 세부 배점·실제 감점 이유·채점 대상 버전·이번 문서의 재채점은 미확인이다. 스타터킷의 양식·실행 요건을 점수표로 해석하지 않는다.

| 점검 대상 | 최종 문서의 처리 |
|---|---|
| 문제·근거 | E1 관찰·E2 자기보고·R1~R9 외부 자료·가설을 구분하고 시점·손실·감정·효과의 미확인 범위를 표시한다. |
| 대안·why_ours | 실제 사용이 확인된 방법과 비교 후보를 구분하고 같은 자세 확인 목표에서 선택 이유를 연결한다. |
| 용어·수치 | 서비스명은 패스트거북이, 시간은 등록 5초·최초 경고 10초·복귀 3초·재경고 60초·자동 리포트 유효 30분으로 통일한다. |
| 상태·저장 | 자리 비움·인식 불가는 판정 보류·연속 타이머 초기화이며 정상 복귀로 세지 않는다. 로그인 없는 같은 PC 브라우저의 로컬 저장이다. |
| 입력·결과·완료 조건 | 기능별 input·output·done과 시나리오별 경고/복귀 횟수·리포트 수·저장/삭제 결과를 명시한다. |
| 독립 흐름 | 각 흐름이 첫 화면에서 자체 기준·기록·연결을 준비하며 이전 S번호의 결과를 재사용하지 않는다. |
| 양식 | 문제정의의 지정 키, 8개 흐름, 1~12단계, 제목 1~120자, expected 1~500자를 검사한다. |
| 자료 격리 | 초기 실험·과거 초안·검토·미채택 보조 숫자를 archive/에 분리하고 현재 계약과 혼동하지 않는다. |
| 실행 한계 | 30분/1분 요건 충돌·카메라·다중 기기 재현을 미확인으로 남긴다. |

P0/P1은 주최측 공식 배점이 아닌 내부 작업 우선순위이다. 근거와 분류는 [validation-plan.md](validation-plan.md)에 정리한다. 실제 정책·용어의 기준은 [planning-policy.yaml](planning-policy.yaml)이다.

문서 검사 16/16은 빈칸·구조 확인이며 기획 점수나 품질 보증이 아니다. 새 경험·발화·효과·수치를 만들어 점수를 채우지 않는다. 실제 대안 사용·반복 빈도·손실·사용 의향은 후속 확인이 필요하다.

등록 저장소의 기본 브랜치 문서 반영과 대시보드 재채점은 구분한다. 문서가 반영되어도 새 점수가 확인되기 전에는 20점대 달성으로 기록하지 않는다. 과거 평가·기획 검토 이력은 [아카이브](../archive/planning-history/README.md)에 보존한다.
