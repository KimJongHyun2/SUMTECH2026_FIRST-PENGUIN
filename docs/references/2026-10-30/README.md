# 현재 문서 검사용 가상 산술 자료

report-calculation.source.json은 기존 tools/check-planning.mjs가 사용하는 가상 리포트 집계 예시이다. 실제 사람의 측정 데이터나 앱/E2E 결과가 아니다. 경고·복귀·시간 정책은 [현재 공통 정책](../../planning-policy.yaml)을 따른다.

이 폴더에 섞여 있던 과거 보완자료·초안은 [archive/planning-history/](../../../archive/planning-history/README.md)로 이동했다. 제공 원문의 값·기능 번호·지시를 현재 제출 계약으로 혼동하지 않도록 본문은 보존하고 위치를 분리했다.
