# 의도 (intent) — 내 카드 찾기

> 기준 문서는 [problem.yaml](problem.yaml)이에요. 이 문서는 "왜 이렇게 만들었나"를 사람 말로 풀어 쓴 것이고, 발표 대본의 뼈대로 써요.

## 한 문장

**카드 혜택표를 "내가 1년에 받는 돈"으로 바꿔 주고, 지금 카드와 비교해 바꿀지 말지까지 알려 준다.**

## 누구의 어떤 순간을 푸나

- **대상:** 카드를 처음 만들거나 바꾸려는 대학생·군인·사회초년생
- **순간:** 첫 카드를 만들 때, 입대할 때, 첫 월급을 받을 때, 쓰던 카드 혜택이 줄었을 때
- **이 사람들이 특히 아픈 이유:** 한 달 지출이 적어서 전월실적(보통 20만~50만 원)을 채우느냐에 따라 혜택이 0원이 되기도 한다. 그런데 이걸 미리 계산해 주는 곳이 없다.

## 지금 사람들이 버티는 방법과 남는 문제

| 지금 방법 | 남는 문제 |
|---|---|
| 지인·은행 창구 추천 | 추천한 사람의 소비 기준이라 내 지출과 맞는지 모른다 |
| 블로그·유튜브 "추천 카드 TOP" | 글쓴이 기준 순위, 내 신분·실적 조건 미반영, 혜택 변경 여부 모름 |
| 금융사 앱·카드 비교 사이트 | 할인율·실적·한도를 내 지출에 직접 대입해야 해서 끝까지 비교하기 어렵다 |
| 뱅크샐러드 같은 자산관리 앱 | 금융 계정 연동이 필요하고, "지금 카드 대비 바꾸면 얼마 더"는 보여 주지 않는다 *(팀이 앱에서 직접 확인 필요)* |

## 우리가 다른 점 (와우 포인트)

1. **금액으로 말한다.** "식비 10% 할인"이 아니라 "당신 지출이면 월 ○○원, 연회비 빼고 연 ○○원"이라고 말해요. 실적을 못 채우면 혜택은 0원이라고 솔직하게 보여 줘요.
2. **지금 카드와 비교한다 (F8).** 추천에서 끝나지 않고 "1위 카드로 바꾸면 연 ○○원 더"처럼 바꿀지 말지 판단할 숫자를 줘요. 지금 카드가 제일 나으면 "바꾸지 않아도 돼요"라고 말해요.
3. **연동·로그인 없이 30초.** 금융 계정을 연결하지 않아요. 지출을 몰라도 "배달 20만, 지하철 6만"처럼 문장으로 쓰면 AI가 칸을 채워요.
4. **근거를 보여 준다.** 순위는 AI가 아니라 공개된 규칙으로 계산해요. 같은 입력이면 같은 결과가 나오고, 분야별로 얼마씩 받는지와 카드사 출처 링크·확인일을 함께 보여 줘요.

## 일부러 안 만드는 것

| 안 만드는 것 | 이유 |
|---|---|
| 로그인·회원가입 | 한 번 계산하고 끝나는 도구라 필요 없다. 입력값을 서버에 저장하지 않는 것이 오히려 장점이다 |
| 마이데이터·카드 내역 연동 | 금융 인증·사업자 자격이 필요하다. 문장 입력(F3)으로 입력 부담을 대신 줄인다 |
| 실시간 크롤링 | 사이트 구조가 바뀌면 깨진다. 출처·확인일을 붙인 데이터 파일로 관리한다 |
| AI가 정하는 추천 순위 | 같은 입력에 다른 답이 나오면 믿을 수 없다. AI는 문장을 숫자로 바꾸는 데만 쓴다 |
| 카드 신청 연결·제휴 | 추천이 제휴 때문에 기운다는 의심을 받지 않도록 대회 범위에서 뺀다 |

## 아직 채워야 하는 근거 (기획 점수)

- **impact.measurable:** 팀원 각자 지금 카드와 지출을 넣어 "지금 카드 연간 순혜택" vs "1위 카드 연간 순혜택" 차이를 구한다. → "팀원 5명 중 n명이 연 평균 ○○원을 덜 받고 있었다"
- **experiences(E1):** 카드를 고를 때 헷갈렸던 실제 장면과 그때 한 말.
- **뱅크샐러드 단점:** 앱을 직접 열어 확인한 뒤 problem.yaml의 `?`를 지운다.
