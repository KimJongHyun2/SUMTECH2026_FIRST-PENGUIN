## 1. 한 문장

**거북목은 본인은 모르고 남이 봐야 안다. 친구 대신 정면 웹캠이 내 자세를 보고, 내가 정한 바른 자세에서 벗어난 채 5분쯤 지나면 "거북이가 되었습니다"라고 알려 준다.**

## 2. 문제 — 누가, 언제, 어디서, 어떻게

| 항목 | 내용 | 상태 |
|---|---|---|
| 누가 | 노트북을 오래 쓰는 사람 — 개발자, 컴퓨터로 회사 업무를 하는 사람 (우리 팀 포함) | 확정 |
| 언제·어디서 | 장소·시간을 가리지 않고, 업무에 **집중할 때면** | 확정 |
| 어떻게 | 허리가 구부정해지고 목이 앞으로 나온다. 집중하고 있어서 **본인은 모른다** | 확정 |
| 어떻게 알게 되나 | 친구가 "너 목이 좀 휘었어. 거북이 같아."라고 말해 줘서 | 확정 |
| 그때 기분 | 기분이 나쁘고 스트레스를 받는다. 건강이 나빠진다 | 확정 |
| 실제 경험 E1 | 친구가 알려 준 장면 — 언제, 무슨 말, 어떻게 넘겼나 | 학생 답 대기 |
| 측정 가능한 영향 | 출처 있는 수치, 또는 팀이 직접 잰 기록 | 학생 답 대기 |

### 왜 아직 아무도 못 고쳤나 (5 Whys)

1. 증상: 거북목이 된다
2. 왜? 구부정한 자세를 오래 유지한다
3. 왜? 업무에 집중하면 자세가 자연스럽게 무너진다
4. 왜? **지금 자기 자세가 어떤지 본인은 모른다 — 다른 사람이 봐야 알 수 있다**
5. 왜 알고 나서도 안 고쳐지나? 스트레칭을 해도 **다시 무너지는 순간은 여전히 아무도 알려 주지 않는다** ← 근본 문제

### 지금 버티는 방법과 남는 문제

| 현재 대안 | 남는 단점 | 우리가 다른 점 |
|---|---|---|
| 자세 교정 의자·베개 | 완치가 안 된다. 의자에 앉아 있어도 집중하면 다시 목이 나온다 | 의자는 자세가 무너져도 알려 주지 않는다. 우리는 무너지는 순간을 잡아낸다 |
| 아플 때 턱 당기기·스트레칭 | 거북목의 확실한 해결 방법이 없어서 이게 전부인데 완치가 안 된다. 아플 때만 하니 그 사이에 모르는 채로 악화된다 | 스트레칭은 아픈 뒤의 사후 대응. 우리는 아프기 전, 나쁜 자세가 이어지는 바로 그때 알려 준다 |

## 3. 해법과 원칙

**정면 웹캠 → 내 바른 자세를 기준으로 저장 → 기준을 벗어난 자세가 일정 시간 이어지면 "거북이가 되었습니다"**

| 원칙 | 내용 | 상태 |
|---|---|---|
| 친구를 대신한다 | 거북목을 알려 주던 건 늘 옆 사람이었다. 그 역할을 노트북에 이미 달린 카메라가 한다. 따로 살 장비가 없다 | 확정 |
| 내 바른 자세가 기준이다 | 사람마다 체형·책상·모니터 위치가 달라서 정해진 "정답 자세"가 없다. 본인이 바르게 앉은 모습을 저장하고, 얼마나 벗어나야 나쁜 자세인지도 그 기준 자세에서 정한다 | 확정 |
| 잠깐은 봐준다 | 순간순간 알리면 시끄러워서 꺼 버린다. 무의식적으로 거북목 자세가 유지되는 시간이 지났을 때만 알린다 | 확정 (시간은 가정 5분) |
| 진단·치료하지 않는다 | "너 지금 거북이야"를 대신 말해 주는 데서 멈춘다 | 확정 |
| 영상은 내 컴퓨터를 떠나지 않는다 | 카메라 영상은 브라우저 안에서만 처리하고 서버로 보내지 않는다 | 확정 |

## 4. MVP 범위

### 만든다

| ID | 기능 | 한 줄 |
|---|---|---|
| F1 | 바른 자세 기준 저장 | 카메라 앞에서 바르게 앉아 저장. 이게 내 기준 |
| F2 | 실시간 자세 판정 | 바른 자세 / 거북이 자세 표시, 거북이 자세가 이어진 시간 표시 |
| F3 | 거북이 알림 | 거북이 자세가 N분 이어지면 "거북이가 되었습니다" |

### 이번에는 안 만든다

| 안 만드는 것 | 이유 | 상태 |
|---|---|---|
| 로그인·회원가입 | 혼자 쓰는 알림이 먼저 동작해야 한다. 기준 자세는 이 브라우저에 저장하면 충분하다 | 가정 |
| 커뮤니티·"최악의 거북이" 랭킹 | 로그인이 전제. 친구 관계를 서비스 안으로 가져오는 다음 단계 | 확정 (보류) |
| 자세 변화 기록·통계 | 알림이 먼저. 기록은 랭킹과 함께 다음 단계 | 가정 |
| 옆모습 카메라·별도 장비 | 정면 웹캠만 쓴다 | 확정 |
| 의학적 진단·치료 안내 | 범위 밖. 거북목을 판정하지 않고 "내 기준에서 벗어났다"만 말한다 | 확정 |
| 모바일 화면 | 노트북·데스크톱 정면캠 앞에서 일하는 장면이 대상 | 가정 (platform: desktop) |

## 5. 사용자 시나리오

화면 글자(메뉴·버튼·문구)는 뒤의 scenarios.yaml과 E2E가 그대로 찾아요. 바꾸면 세 곳을 같은 commit에서 고쳐요.

### S1. 처음 와서 기준 자세를 저장한다 (F1)

1. `/`를 연다 → 서비스 이름 **패스트거북이**와 "친구 대신 웹캠이 내 거북목을 알려 줘요"가 보인다
2. **시작하기**를 누른다 → `/setup`
3. **카메라 켜기**를 누른다 → 브라우저 카메라 허락 → 내 영상이 보이고 얼굴·어깨 위치가 표시된다
4. 안내 "등을 펴고 턱을 살짝 당긴 바른 자세로 앉아 주세요"를 보고 바르게 앉는다
5. **기준 저장**을 누른다 → "기준 자세가 저장됐어요" → `/watch`로 이동
- 기대 결과: 새로고침해도 `/watch`에서 기준이 남아 있다

### S2. 일하는 동안 거북이가 되면 알림을 받는다 (F2·F3)

1. `/watch`에 기준이 있다 → **감지 시작**을 누른다 (처음이면 **알림 허용**도 누른다)
2. 바르게 앉아 있다 → 화면에 **바른 자세**, 거북이 시간 `0:00`
3. 목을 내밀거나 화면 쪽으로 숙인다 → **거북이 자세**로 바뀌고 시간이 올라간다
4. 알림 시간(기본 5분)을 넘긴다 → 브라우저 알림 + 소리 + 화면에 **거북이가 되었습니다**
5. 자세를 고친다 → **바른 자세**, 알림 멈춤, 시간 `0:00`
- 기대 결과: 다른 창에서 일하고 있어도 4번 알림이 보인다

### S3. 자리가 바뀌어 기준을 다시 저장한다 (F1)

1. `/watch`에서 **기준 다시 저장**을 누른다 → `/setup`
2. S1의 3~5를 다시 한다
- 기대 결과: 새 기준으로 판정된다

### S4. 카메라를 거부했다 (F1 실패)

1. `/setup`에서 **카메라 켜기** → 브라우저에서 거부
2. "카메라를 쓸 수 없어요. 주소창의 카메라 아이콘에서 허락해 주세요"가 보이고 **기준 저장**은 비활성
- 기대 결과: 저장되지 않고, 이유가 보인다

### S5. 얼굴이 안 보인다 (F1·F2 실패)

1. 카메라는 켜졌지만 자리를 비우거나 얼굴이 화면 밖
2. `/setup`: "얼굴과 어깨가 보이게 앉아 주세요", **기준 저장** 비활성
3. `/watch`: 상태가 **감지 중단**으로 바뀌고 거북이 시간은 멈춘다(0으로 돌리지 않음)
- 기대 결과: 자리를 비운 시간은 거북이 시간에 들어가지 않는다

| 요소 | 글자 | 동작 |

| 안심 문구 | 영상은 내 컴퓨터 안에서만 처리되고 어디에도 보내지 않아요 | |
| 버튼 | **시작하기** | 기준이 없으면 `/setup`, 있으면 `/watch` |

### `/setup` 기준 자세 저장 (F1)

| 요소 | 글자 | 규칙 |
|---|---|---|
| 영상 | 내 카메라 영상 + 얼굴·어깨 위치 표시 | 좌우 반전(거울처럼) |
| 버튼 | **카메라 켜기** | 허락 전에만 보임 |
| 안내 | 등을 펴고 턱을 살짝 당긴 바른 자세로 앉아 주세요 | 카메라 켜진 뒤 |
| 버튼 | **기준 저장** | 얼굴·어깨가 잡혀 있을 때만 활성. 누르면 2초간 측정해 평균을 기준으로 저장 |
| 성공 문구 | 기준 자세가 저장됐어요 | 1초 뒤 `/watch` |
| 오류 | 카메라를 쓸 수 없어요. 주소창의 카메라 아이콘에서 허락해 주세요 | 거부·장치 없음 |
| 오류 | 얼굴과 어깨가 보이게 앉아 주세요 | 인식 실패 |

### `/watch` 감지 화면 (F2·F3)

| 요소 | 글자 | 규칙 |
|---|---|---|
| 상태 | **바른 자세** / **거북이 자세** / **감지 중단** / **감지 꺼짐** | 크게, 색으로도 구분 |
| 시간 | 거북이 시간 `m:ss` | 거북이 자세 동안만 올라감. 바른 자세로 돌아오면 `0:00` |
| 영상 | 작은 미리보기 + 얼굴·어깨 위치 | 끄기 가능(**영상 숨기기**), 감지는 계속 |
| 버튼 | **감지 시작** ↔ **감지 멈추기** | |
| 버튼 | **알림 허용** | 브라우저 알림 권한이 없을 때만 보임 |
| 설정 | 알림 시간: `5`분 | 가정 기본 5분. 1분 단위, 최소 0.2분(12초)… 데모·E2E용으로 짧게 가능 |
| 설정 | 소리 켜기/끄기 | 기본 켬 |
| 버튼 | **기준 다시 저장** | `/setup` |
| 알림 | **거북이가 되었습니다** | 화면 배너 + 브라우저 알림 + 소리. 바른 자세로 돌아오면 모두 멈춤 |
| 안내 | 기준이 없으면 "먼저 바른 자세를 저장해 주세요" + **기준 저장하러 가기** | |

없는 주소는 404 화면("없는 페이지예요" + **첫 화면으로**).

## 7. 기능 규칙

### F1 기준 자세 저장

- 저장하는 값: 기준 시점의 얼굴 크기, 얼굴 중심 위치, 어깨선 높이·너비 — 정면 카메라에서 바로 잴 수 있는 것들. **확정**: 영상 자체는 저장하지 않는다
- 저장 위치: 이 브라우저(localStorage). 로그인 없음 — **가정**
- 2초간 여러 프레임을 평균해 저장 — **가정**

### F2 자세 판정 — **실험**

정면 카메라는 옆에서 보이는 "귀가 어깨보다 앞으로 나온 거리"를 직접 못 잰다. 그래서 **기준 자세와 비교한 변화**로 판정한다. 후보 신호:

| 신호 | 거북이 자세일 때 변화 | 뜻 |
|---|---|---|
| 얼굴 크기 ÷ 어깨 너비 | 커진다 | 얼굴이 화면 쪽으로 다가옴 (목을 내밈) |
| 얼굴 중심 ~ 어깨선 세로 거리 | 줄어든다 | 고개를 숙임·어깨가 올라옴 |
| 얼굴 중심 높이 | 내려간다 | 구부정해짐 |

- 판정: 신호 중 하나라도 기준 대비 **X% 이상** 벗어나면 거북이 자세. X는 실험으로 정한다(시작값 가정 15%)
- 떨림 방지: 상태가 바뀌려면 **2초** 연속 같은 판정이어야 한다 — 가정
- 얼굴·어깨가 안 잡히면 **감지 중단**, 시간은 멈추고 유지

### F3 거북이 알림

- 거북이 시간이 설정값(기본 **5분**, 가정)에 닿으면 알림: 화면 배너 + 브라우저 알림(Notification API) + 소리 — **가정** (사용자는 다른 창에서 일하므로 화면 표시만으로는 부족하다)
- 바른 자세로 2초 이상 돌아오면 알림 멈춤, 시간 `0:00`
- 알림 뒤에도 계속 거북이 자세면 **1분마다** 다시 알림 — 가정
- 알림 권한이 없으면 화면 배너 + 소리만, **알림 허용** 버튼 노출

## 8. 성공 기준

| 구분 | 기준 |
|---|---|
| 동작 | 팀원이 S1→S2를 그대로 해서, 거북이 자세를 알림 시간만큼 유지하면 다른 창에서도 "거북이가 되었습니다"를 받는다 |
| 정확도 (실험) | 팀원 3명이 각자 기준 저장 뒤 ① 바르게 앉기 1분 ② 의도적 거북이 1분을 할 때, ①에서 거짓 알림 0회, ②에서 거북이 자세 판정이 유지된다 |
| 신뢰 | 영상·이미지가 네트워크로 나가지 않는다 (브라우저 네트워크 탭으로 확인) |
| 제출 | `docker compose up --build`로 뜨고, S1~S5가 E2E로 통과하고, 공개 URL에서 같은 동작 |

## 9. 비기능 요구

- 카메라 접근은 HTTPS 또는 localhost에서만 가능 → 배포는 HTTPS 필수
- 데스크톱 브라우저(Chrome 최신) 기준 — 가정
- 감지 중 CPU가 노트북 팬이 돌 정도로 높지 않아야 한다(사용자는 일하는 중) → 초당 처리 프레임을 낮게(예: 5fps) — 가정
- 영상·이미지·좌표를 서버로 보내지 않는다 — 확정
