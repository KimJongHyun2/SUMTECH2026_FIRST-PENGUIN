# 과거 기획 원문·검토 기록

references/2026-10-30의 제공 보완자료·초안과 과거 PRD 검토·구현 대조·통합 이력을 보존한다. 문서 안의 옛 기능/흐름 번호·서비스명·시간값·기획 제안·실행 지시는 당시 기록이며 현재 요구사항이 아니다.

현재 정책은 [planning-policy.yaml](../../docs/planning-policy.yaml), 제출 명세는 [problem.yaml](../../docs/problem.yaml)·[scenarios.yaml](../../docs/scenarios.yaml), 전체 설명은 [prd.md](../../docs/prd.md)를 따른다. 현재 점수 기준은 30점 만점에 14.6점이며 과거 기록의 13.5점과 구분한다.

가상 리포트 산술 JSON은 기존 문서 검사에서 사용하므로 docs/references/2026-10-30/report-calculation.source.json에 유지했다. 이것은 실제 사용자의 측정 데이터·앱 실행 결과가 아니다.

planning-policy.before-cleanup.yaml과 progress.before-cleanup.md는 이번 정리 직전의 정책 제안·진행 기록 스냅샷이다. 현재 정책이나 현재 파일 위치를 설명하는 문서가 아니다.
