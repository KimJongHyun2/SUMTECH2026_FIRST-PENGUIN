# 핵심 기술 검증 플랜

> 판정 기준(몇 도, 몇 초)의 근거는 [02_판정기준_근거.md](./02_판정기준_근거.md)를 참고합니다.

## 목표

UI를 만들기 전에 **핵심 기술 3가지가 실제로 되는지** 3~4일 안에 확인하고, 결과에 따라 기능 명세를 확정하거나 수정한다.

| # | 검증 대상 | 한 줄 질문 |
| --- | --- | --- |
| T1 | 정면 웹캠 판별 | 정면 신호만으로 바른 자세와 거북목을 구분할 수 있나? |
| T2 | 폰 옆모습 각도 | 폰 브라우저로 귀–어깨 각도를 안정적으로 잴 수 있나? |
| T3 | 정면 → 각도 보정 | 정면 신호로 옆모습 각도를 맞힐 수 있나? |

**진행 순서: T1 → T2 → T3**
- T3는 T1과 T2가 모두 돼야 진행할 수 있다.
- T1이 실패하면 서비스 구조 자체를 바꿔야 하므로 가장 먼저 한다.

## 0. 준비 (반나절)

### 준비물
- [ ] 노트북 (실제 사용자와 비슷한 일반 노트북 웹캠)
- [ ] 스마트폰 + 거치대 (책이나 컵에 기대도 됨)
- [ ] 실험 참여자 **3명 이상** (안경 착용, 긴 머리, 체형이 다른 사람이 섞이면 좋음)

### 개발 환경
- [ ] 검증용 웹페이지 1개 (React 또는 순수 HTML/JS)
- [ ] 라이브러리: **MediaPipe Tasks Vision** (`PoseLandmarker`, `FaceLandmarker`)
- [ ] **HTTPS 환경 준비**
  - 브라우저 카메라는 HTTPS에서만 작동한다.
  - 노트북은 `localhost`라 괜찮지만, **폰에서 노트북 개발 서버에 접속하면 카메라가 켜지지 않는다.**
  - 해결: ngrok 같은 터널 도구로 HTTPS 주소를 만들거나, Vercel/Netlify에 바로 배포해서 테스트한다.

### 공통 기능
- [ ] 모든 테스트 페이지에 **기록 시작/중지 + 라벨 선택 + CSV 다운로드** 버튼
- 분석은 이 CSV로 한다.

## T1. 정면 웹캠 판별 (1~1.5일)

### 구현
매 프레임(초당 2~5회)마다 아래 값을 계산해 화면에 표시하고 기록한다.

| 신호 | 계산 | 사용할 점 |
| --- | --- | --- |
| ① 머리 내밂 | 얼굴 너비 ÷ 어깨 너비 | 양쪽 귀(또는 얼굴 외곽), 양쪽 어깨 |
| ② 목 길이 | (귀 평균 y − 어깨 평균 y) ÷ 어깨 너비 | 귀, 어깨 |
| ③ 고개 숙임 | 머리 pitch 각도 | `FaceLandmarker`의 얼굴 변환 행렬 옵션 |
| ④ 어깨 기울기 | 양쪽 어깨 y 차이 ÷ 어깨 너비 | 어깨 |

함께 기록할 값: **어깨 인식 신뢰도(visibility)**, **처리 속도(fps)**

> **왜 어깨 너비로 나누나?**
> 의자를 당겨 앉으면 얼굴과 어깨가 **같이** 커져 비율은 그대로다(정상).
> 머리만 내밀면 얼굴만 커져 비율이 증가한다(거북목).
> 비율로 비교해야 "의자 당김"을 거북목으로 잘못 판단하지 않는다.

### 실험
참여자마다 아래 **6가지 자세를 30초씩** 취하며 라벨을 붙여 기록한다.

| 라벨 | 설명 | 기대 판정 |
| --- | --- | --- |
| 바른 자세 | 기준 | 정상 |
| 거북목 약 | 머리만 살짝 앞으로 | 나쁨 |
| 거북목 강 | 머리를 확실히 앞으로 | 나쁨 |
| 고개 숙임 | 노트북을 내려다봄 | 나쁨 |
| **의자 당김** | 바른 자세 그대로 몸 전체를 화면 쪽으로 | **정상 (오탐 함정)** |
| **필기** | 고개 숙여 노트에 글씨 쓰기 | 짧으면 정상 (시간 기준 테스트) |

- [ ] 조명 2가지(밝은 낮 / 어두운 밤 스탠드)에서 반복 (선택)

### 분석
- 라벨별로 신호 ①~④의 **평균과 흔들림(표준편차)** 표 작성
- 바른 자세와 거북목의 값 분포가 **얼마나 겹치는지** 그래프로 확인 (히스토그램 또는 박스플롯)

### 성공 기준 (제안값, 상황에 맞게 조정)
- [ ] 바른 자세와 거북목(강)의 신호 차이가 **흔들림보다 확실히 큼** (분포가 거의 안 겹침)
- [ ] **의자 당김**이 거북목처럼 보이지 않음
- [ ] 일반적인 노트북 자세에서 어깨 인식 비율 **80% 이상**
- [ ] 일반 노트북에서 **초당 2회 이상** 처리

### 실패하면
| 상황 | 대안 |
| --- | --- |
| 어깨가 자주 안 잡힘 | 얼굴 신호(① 얼굴 크기, ③ pitch)만으로 판별하고, 온보딩에서 화면 각도 조정 안내 |
| 거북목 "약"만 구분 안 됨 | MVP는 "강"만 잡는 것으로 목표 축소 |
| 의자 당김 오탐이 심함 | **T2와 T3의 중요도가 올라감** (옆모습이 이 문제를 해결) |

## T2. 폰 옆모습 각도 (1일)

### 구현
- 폰 브라우저에서 `PoseLandmarker` 실행
- **카메라 쪽 귀와 어깨**를 잇는 선이 **수평선과 이루는 각도** 계산
- 귀·어깨 인식 신뢰도, fps 함께 기록

> 의학적 CVA는 목 뒤 C7 척추를 기준으로 하지만, 여기서는 **어깨 점으로 근사**한다.
> 절대값보다 **변화량을 일관되게 잡는지**가 더 중요하다.

### 실험
1. **안정성:** 바른 자세로 1분간 가만히 앉아 각도 흔들림 측정
2. **민감도:** 바른 자세 → 거북목 약 → 강을 각 30초씩
3. **환경 변화:**
   - 폰 거리: 50cm / 1m
   - 폰 높이: 책상 / 어깨 높이
   - 후드나 긴 머리로 귀를 가린 상태
4. **정답 비교:** 같은 순간 옆모습 사진을 찍고, 사진 위에서 **직접 귀와 어깨를 찍어 각도를 재서** 앱 값과 비교 (각도 측정 웹툴이나 앱 사용 가능)

### 성공 기준
- [ ] 가만히 있을 때 흔들림 **±2° 이내**
- [ ] 사진 수동 측정과 차이 **±5° 이내**
- [ ] 바른 자세와 거북목 강의 각도 차이가 **흔들림보다 확실히 큼**
- [ ] 폰에서 **초당 2회 이상**, 10분 사용 시 발열이나 끊김이 심하지 않음
- [ ] 아이폰(Safari)과 안드로이드(Chrome) **둘 다** 확인

### 실패하면
| 상황 | 대안 |
| --- | --- |
| 흔들림이 큼 | 1~2초 이동평균으로 부드럽게 처리 |
| 귀가 자주 가려짐 | 귀 대신 눈이나 코 점으로 대체한 각도 테스트 |
| 폰 성능 부족 | 처리 횟수를 초당 1회로 낮추거나 저해상도 사용 |

## T3. 정면 → 각도 보정 (1~1.5일)

### 구현
1. **폰 → 노트북 연결**
   - 폰은 영상이 아니라 **각도 숫자만** 보낸다.
   - 노트북은 받은 값을 정면 신호와 함께 저장한다.
   - Supabase Realtime이나 Firebase를 쓰면 서버를 직접 만들지 않아도 된다.
2. **시간 맞추기**
   - 두 기기의 시계가 다를 수 있으므로 **노트북이 받은 시각 기준**으로 정면 값과 짝을 짓는다.

### 실험
1. 두 카메라로 동시에 기록하며 **바른 자세 → 점점 거북목 → 다시 바른 자세**를 천천히 2분간 반복
2. **다음 날** 보정 없이 같은 실험을 한 번 더 (시간이 지나도 보정이 유지되는지 확인)

### 분석
- 입력: 정면 신호 ①②③
- 정답: 옆모습 각도
- 데이터 **앞 70%로 선형 회귀 학습 → 뒤 30%로 검증**
- 도구: CSV를 Python(pandas, scikit-learn)으로 분석. 학습한 식은 단순해서 서비스에서는 JS로 옮기면 된다.
- 결과 지표: **평균 오차(MAE, 평균 몇 도 틀리는지)**

### 성공 기준
- [ ] 같은 날 검증 데이터에서 평균 오차 **5° 이내**
- [ ] 다음 날 재보정 없이 **7° 이내**
- [ ] 참여자마다 개별 보정했을 때 모두 위 기준 충족

> T3가 성공하면 판정 기준을 **각도(°)** 단위로 쓸 수 있어
> 선행 연구 기준(중립 대비 15°/20°, CVA 48°)을 그대로 적용할 수 있다.
> 자세한 내용은 [02_판정기준_근거.md](./02_판정기준_근거.md) 참고.

### 실패하면
| 상황 | 대안 |
| --- | --- |
| 같은 날도 오차가 큼 | 각도 대신 **"바른 / 약간 / 심함" 3단계 분류**로 목표 낮추기 |
| 다음 날만 틀어짐 | 매일 짧은 재보정(10초 바른 자세)으로 보완 |
| 사람마다 편차가 큼 | 개인별 보정을 필수 단계로 유지 |
