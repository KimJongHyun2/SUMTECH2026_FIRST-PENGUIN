# 바른목 (거북목 알림 웹) + 자세 기술 검증 도구

- **서비스 화면 (`/`)**: 노트북 웹캠으로 바른 자세 기준을 잡고, 거북목이 30초 이어지면 알림. 오늘의 자세 리포트(바른 자세 비율, 시간대별, 앉은 뒤 처음 무너지기까지 걸린 시간)는 브라우저 localStorage에만 저장한다.
  - 판정 로직: `src/posture.js` (초기 기준값은 p1 T1 데이터에서 잡음, 근거는 docs/02)
  - 리포트 집계: `src/report.js`
- **실험 도구 (`/lab.html`)**: [docs/01_기술검증_플랜.md](docs/01_기술검증_플랜.md)의 T1·T2·T3를 직접 실험하기 위한 웹페이지와 분석 스크립트.
  판정 기준의 근거는 [docs/02_판정기준_근거.md](docs/02_판정기준_근거.md).

## 실행

```bash
npm install
npm run dev
```

- 노트북: `https://localhost:5173`
- 폰: 터미널에 찍힌 **Wi-Fi 주소** (예: `https://192.168.0.118:5173`)
  - 노트북과 **같은 Wi-Fi**에 연결돼 있어야 한다.
  - 자체 서명 인증서라 경고가 뜬다 → "고급 → 계속 진행".
  - 안 열리면 Windows 방화벽에서 Node.js 허용을 확인한다.
- 주소 끝에 `?model=full`을 붙이면 더 정확하지만 느린 모델을 쓴다.
- **카메라 시작 후 처음 3~5초는 모델 준비로 느리다.** 기록은 숫자가 안정된 뒤 시작한다.

> 플랜에는 폰↔노트북 연결에 Supabase/Firebase를 적었지만, 계정 없이 쓰도록
> 개발 서버(`vite.config.js`) 안의 WebSocket 중계(`/relay`)로 대신했다.

## 페이지

| 페이지 | 기기 | 용도 |
| --- | --- | --- |
| `index.html` | 노트북 | 서비스 화면 (기준 잡기 → 실시간 판정 → 알림 → 오늘의 리포트) |
| `lab.html` | 아무거나 | 실험 도구 링크 모음 |
| `front.html` | 노트북 | T1 정면 신호 기록. 폰 옆모습 값이 오면 같은 행에 함께 기록 (T3) |
| `side.html` | 폰 | T2 옆모습 각도 기록 + 노트북으로 전송 + 원본 사진 저장 |
| `angle.html` | 아무거나 | 저장한 사진에서 귀·어깨를 직접 찍어 정답 각도 측정 (T2 정답 비교) |

모든 페이지 공통: 참여자 입력 → 라벨 선택 → **기록 시작** → 유지 → **기록 중지** → **CSV 저장**.
라벨은 기록 중에 바꿔도 된다. 저장한 CSV는 `data/` 폴더에 모은다.

## 실험 순서

### T1 정면 웹캠 (`front.html`)
1. 참여자 이름 입력, **기준 잡기**로 바른 자세 기준값을 확인한다 (화면 표시용).
2. **고개를 숙였을 때 pitch가 어느 방향(+/−)으로 움직이는지** 먼저 확인한다.
3. 라벨 6개(`바른자세`, `거북목_약`, `거북목_강`, `고개숙임`, `의자당김`, `필기`)를 각 30초 기록한다.
4. 참여자 3명 이상 반복한다. 조명을 바꿔 반복하면 더 좋다.

### T2 옆모습 (`side.html` + `angle.html`)
1. 폰을 옆에 세우고 귀·어깨가 보이게 맞춘다. **조건** 칸에 `50cm_책상`처럼 적는다.
2. `정지_1분` 라벨로 1분간 가만히 → 흔들림 측정.
3. `바른자세` → `거북목_약` → `거북목_강` 각 30초.
4. 조건을 바꿔(거리, 높이, 귀 가림) 반복한다.
5. 자세마다 **사진 저장** → `angle.html`에서 사진을 열어 귀·어깨를 클릭 → **비교 CSV 저장**.
6. 아이폰(Safari)과 안드로이드(Chrome) 둘 다 확인한다.

### T3 보정 (`front.html` + `side.html` 동시에)
1. 노트북 `front.html`과 폰 `side.html`을 함께 켠다. 노트북 화면에 "옆모습 72.4° (120ms 전)"처럼 보이면 연결된 것.
2. `front.html`에서 라벨 `보정_연속`으로 기록하며 **바른 자세 → 점점 거북목 → 다시 바른 자세**를 2분간 천천히 반복한다.
3. **다음 날** 같은 방식으로 한 번 더 기록한다.

## 분석

```bash
python analysis/analyze.py t1 data/front_*.csv
python analysis/analyze.py t2 data/side_*.csv
python analysis/analyze.py compare data/compare_*.csv
python analysis/analyze.py t3 data/front_p1_day1.csv --next-day data/front_p1_day2.csv
```

- 각 명령은 플랜의 성공 기준을 **PASS / FAIL**로 출력하고, 그래프는 `results/`에 저장한다.
- T3는 참여자별 **JS용 보정식**도 출력한다. 서비스에서 그대로 옮겨 쓰면 된다.
- 성공 기준 숫자는 `analysis/analyze.py` 위쪽 상수에서 바꾼다.
- 결과는 플랜 문서의 **결과 정리** 표에 옮겨 적는다.
