# 과거 자료 아카이브

현재 제출 기획과 과거 실험·검토를 분리하는 보관소이다. 이 폴더의 서비스명·시간값·가설·지시·검증 결과는 당시 기록이며 현재 요구사항이 아니다. 현재 기준은 [문제정의](../docs/problem.yaml)·[사용자 흐름](../docs/scenarios.yaml)·[구현 설계](../docs/prd.md)이다.

- [초기 자세 실험 도구](posture-experiments/README.md)는 front·side·angle·lab 화면과 전용 분석·기술검증 자료이다.
- [과거 기획 원문·검토 기록](planning-history/README.md)은 팀 원문·이전 계약·검토 이력을 보존한다.

자료 이동 자체가 근거·실험의 유효성을 판정한 결과는 아니다. 공식 제출 경로는 docs/problem.yaml과 docs/scenarios.yaml이다.
