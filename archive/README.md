# 과거 자료 아카이브

이 폴더는 현재 제출 기획과 초기 실험 자료를 분리하기 위한 보관소이다. 아래 파일의 서비스명·시간값·가설·지시문·검증 결과를 현재 요구사항으로 적용하지 않는다. 현재 계약은 [공통 정책](../docs/planning-policy.yaml), [문제정의](../docs/problem.yaml), [독립 시나리오](../docs/scenarios.yaml), [PRD](../docs/prd.md)이다.

- [초기 자세 실험 도구](posture-experiments/README.md)는 front·side·angle·lab 화면, 전용 스크립트·분석·기술검증 문서를 보관한다.
- [과거 기획 원문·검토 기록](planning-history/README.md)은 이전 보완자료·초안·검토 이력을 보관한다. 현재 제출 문서는 아니다.

폴더 이동은 실험이나 근거의 유효성을 판정한 결과가 아니다. 원문을 삭제하거나 현재 사실로 재작성하지 않고 보존했다. 주최측이 지정한 제출 경로는 docs/problem.yaml과 docs/scenarios.yaml이다.
