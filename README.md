# SUMTECH2026 FIRST-PENGUIN — 카드 지갑 코치

이미 가진 카드 몇 장을 등록해 두면, **결제하는 순간 어떤 카드로 내야 가장 이득인지**와 **한 달 동안 카드를 어떻게 나눠 써야 실적과 혜택을 모두 챙기는지** 알려 주는 웹 서비스예요.

> 금융 앱은 "어떤 카드를 새로 만들지"를 추천해요. 우리는 "이미 가진 카드를 어떻게 쓸지"를 알려 줘요.

- 문제정의·기능 명세: [docs/problem.yaml](docs/problem.yaml)
- 핵심 사용자 흐름: [docs/scenarios.yaml](docs/scenarios.yaml)
- 진행 기록: [progress.md](progress.md)

## 구현 설계 (요약)

- 로그인 없음. 카드 데이터만 서버 DB에 있고, 내 지갑·결제 기록은 브라우저 localStorage(`wallet-v1`)에만 저장해요.
- 카드 정보는 실행 중에 크롤링하지 않고, 대회 기간에 카드사 공개 상품 페이지에서 모은 `data/cards.json`을 앱 시작 시 DB에 시드해요. 카드마다 출처 URL과 정보 확인일을 저장해요. 예시 지갑은 `data/example-wallet.json`.
- 결제 순간 추천(F3): 지난달 실적 충족 카드만 할인 → min(금액 × 할인율, 남은 혜택 한도, 남은 카드 전체 한도) 큰 순 → 같으면 "이 결제로 다음 달 혜택 확보" 카드 먼저.
- 한 달 플랜(F6): 9개 분야를 지갑 카드(최대 5장)에 배정하는 모든 조합을 계산해, 실적을 채운 카드의 혜택 합이 가장 큰 배정을 골라 "주로 쓰는 카드 한 장으로 다 낼 때"와 비교해요.
- 추천·플랜은 규칙 계산이라 같은 입력이면 같은 결과예요. AI(AI Gateway)는 가게 이름 → 결제 분야 분류(F4)에만 써요.
