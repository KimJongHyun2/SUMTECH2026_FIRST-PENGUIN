# SUMTECH2026 FIRST-PENGUIN — 패스트거북이

패스트거북이는 노트북으로 공부·작업하는 동안 개인 기준 대비 자세 변화를 감지하고, 지속 이탈 알림과 기록·리포트로 사용자의 자기 조정과 거북목 예방을 돕는 서비스이다. 핵심 문제는 작업에 몰입하면 자세 변화를 제때 알아차리기 어렵고, 고쳐 앉아도 같은 자세를 반복한다는 점이다. 위험 감지는 지속적인 개인 기준 이탈의 감지를 뜻하며 의학적 위험도 계산·진단·치료를 뜻하지 않는다. 예방 효과는 검증 대상이다.

현재 기획은 등록 5초·최초 경고 10초·복귀 3초·재경고 60초·자동 리포트 유효 30분을 기준으로 한다. 자리 비움은 판정 보류·연속 타이머 초기화이며 기록은 로그인 없이 같은 PC 사이트·브라우저 프로필에 로컬 저장하는 원칙이다.

기획 평가는 **30점 만점에 현재 14.6점**, 목표는 **20점대 이상**이다. 실제 재채점은 미확인이다. 기획 문서와 병행 개발된 초기 구현은 구분한다. `posture-web/`에 서비스·기술 검증 코드가 있지만 최신 기획 전체의 구현·배포·E2E 검증 완료를 뜻하지 않는다. 기존 정합성 작업에서 기획 문서 정리와 초기 실험 파일 격리를 진행했다. 이후 예방 목적과 위험 감지 범위를 명확히 하고 초기 앱의 서비스명·소개·상태·알림·리포트 문구를 맞췄다. 감지·경고·저장 알고리즘은 유지하며 초기 앱의 기본 전방 이탈 경고 30초와 기획의 최초 경고 10초 차이는 남아 있다.

문서 검사는 `tools` 디렉터리에서 `npm ci`로 기존 의존성을 준비한 뒤 저장소 루트에서 실행한다.

```sh
node tools/check-problem.mjs
node tools/check-planning.mjs
```

이 검사는 문서 구조·참조·가상 구간 산술을 확인하며 앱 실행·주최측 재현·기획 재채점을 대신하지 않는다. 스타터킷 양식의 키·단계 수·문자 수도 별도로 대조했으며 실제 결과는 진행 기록에 남긴다. 자동 리포트의 실제 30분 시험과 흐름당 로컬 1분 이내 요건, 카메라·다중 기기 재현 방식은 미해결이다.

초기 구현 실행 안내는 [posture-web/README.md](posture-web/README.md)에 있다. 과거 정적 확인에서 발견한 기획과 구현의 차이는 [구현 대조 기록](archive/planning-history/implementation-status.md)에 있다. 이번 작업에서 앱·Docker·E2E·배포는 실행하지 않는다.
